# Editing the Zo Media website (for editors)

You edit the site in **Sanity Studio**. Nothing you do there can break the design.

**Open it:** the link your administrator gives you (looks like `https://zomedia.sanity.studio`). Sign in with the Google/email account you were invited with.

## Edit something
1. Pick a section on the left — **Books**, **People**, **Special Projects**, or **Site Settings**.
2. Click the item, change the fields, and read any grey help text under a field.
3. Click **Publish** (bottom right). Your change appears on the live site in about **1–2 minutes**.

Until you press Publish, nothing changes on the website — you can save as you go.

## Add a book
**Books → + (Create)**. Fill in: Title → click **Generate** next to Address → Author → Category → Short description (1–2 sentences) → Cover image **and its description** → prices (like `$14.95`) → Order (lower number appears first). Leave **Where to buy** empty until the book is on sale. Tick **Forthcoming** for books not yet released. **Publish.**

## Add or edit a person
**People → pick a group**. Name, role, bio, and a headshot (optional). Only publish what the person has approved. **Order** controls the list order within the group.

## Remove something
Open it → the **⋯ menu** → **Delete**. (Prefer to hide a book temporarily? Open it → **⋯ → Unpublish.**)

## Good habits
- Always add the **image description** (alt text) — it helps blind readers and search engines.
- Keep short descriptions under about 300 characters.
- Prices must look like `$14.95`.
- Check the live page after publishing. If something looks wrong, tell the web team — don't try to fix it by deleting and re-creating.

## Need something changed that isn't here?
Page layout, menus, headlines on the home page and legal pages are managed by the web team. Email them what you'd like changed.
